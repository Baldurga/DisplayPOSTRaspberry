# DisplayPOSTRaspberry

*** Utiliza una Raspberry Pi Pico como tarjeta diagnostico POST con Display ***

Este es un proyecto para usar una Raspberry Pi Pico para leer los códigos POST de una placa base y mostrarlos en un display.

El objetivo (cumplido) era conseguir una tarjeta de diagnóstico por muy poco dinero, en este caso por menos de 5 euros, y que fuera lo más universal posible (para cualquier placa base). En mi caso encontré los componentes en Aliexpress, pero el precio puede variar y recuerda que siempre puedes tener una tienda cerca que te puede vender lo mismo a un buen precio ;-)

Mencionar que no hubiera sido posible llevar a cabo este proyecto sin el magnifico trabajo de MrGreensWorkshop, su código ha sido la base sobre la cual incorporar la programación del display.

Pido disculpas de antemano porque estuve conectando y desconectando posteriormente mi Pico, con la mala pata que una de las veces crucé el positivo y el negativo... así que me la he cargado y no pude verificar el último código.

Espero pueda ser de ayuda, y tengo un video explicando el proceso y como conectar en mi canal Balditech de Youtube.
